# Chill & Enjoy — Next.js Glass Music Player

A Spotify-inspired personal music player built with Next.js, TypeScript and CSS glassmorphism.

## Features

- Automatic song discovery from `public/songs`
- Play / pause
- Previous / next
- Shuffle
- Repeat
- Progress seeking
- Volume control
- Fullscreen
- Keyboard controls
- Glassmorphism UI
- Warm bedroom background
- Responsive design

## Run

```bash
npm install
npm run dev
```

Open:

`http://localhost:3000`

## Add your songs

Put `.mp3`, `.m4a`, `.wav` or `.ogg` files in:

`public/songs`

Example:

```text
public/
  songs/
    Aabaad Barbaad.mp3
    Sanam Re.mp3
    Tum Mile.mp3
```

Refresh the website. The songs will automatically appear.

## Keyboard shortcuts

- Space — Play / Pause
- Left Arrow — Previous
- Right Arrow — Next

## Background

The included `public/background.png` is the warm bedroom image used by the interface.

For a public website, only use audio files that you have the rights or permission to distribute.
